# Android 版 計画（v0：自分用 APK）

## ゴール
乗務用のサブ Android に入れて、
1. 寝る締め切り（lastcall／閉店／ハード／出発）を**確実に通知**する
2. 寝る・起きた・帰った・気分・今日休む を**ワンタップ**で記録する（ホーム画面ウィジェット）
3. スマホの画面利用から**睡眠を推定**する補助データを取る
4. 訪看さん向けレポートを**スマホから開いて見せる／共有**できる

データは PC 版と共有する（形式は [data-format.md](data-format.md)）。iOS は Mac が届いてから同じコードベースに足す。

## 前提と決めたこと
| 項目 | 決定 |
|---|---|
| 技術 | Kotlin Multiplatform ＋ Compose Multiplatform（今は Android ターゲットだけビルド） |
| 配布 | 自分用 APK（サイドロード）。Play 配布は v1 以降に別途検討 |
| 計算の正 | PC 版（`schedule.json` を読むだけ）。スマホ単体の計算は v1 で `shared` に移植 |
| データ置き場 | 端末内 ＋ Google ドライブの同期フォルダ（サーバーに健康っぽいデータを貯めない） |
| 実装 | Claude Code（Fable Max）に書かせる。人間はレビューと実機確認 |

## 気をつけること（1 つだけ）
サブ端末やから、**スマホを触ってない＝寝てる、とは言えへん**（メインは iPhone）。画面利用は「この時間は起きてた」の証拠としてだけ使い、寝てた判定は PC の無操作・『ねる』の記録と組み合わせる。

## モジュール構成
```
app/
  shared/            KMP 共通（commonMain）
    model/           Event, ScheduleDay, Settings …（data-format.md と 1:1）
    schedule/        schedule.json の読み込み、通知を出す時刻の一覧化
    intent/          話し言葉の判定（PC 版の detect_intents を移植。v1）
    sync/            同期フォルダの読み書き（interface。実装は各 OS）
  androidApp/
    ui/              Compose 画面（今日・記録・設定・レポート）
    widget/          Glance のホーム画面ウィジェット（寝る／起きた／ただいま／気分）
    notify/          AlarmManager／WorkManager で通知の予約
    usage/           UsageStatsManager で画面 ON/OFF を集計
    drive/           Google ドライブの同期実装
  iosApp/            （Mac が来てから）
```

## 画面
1. **今日**：次の乗務、閉店・ハード・出発の時刻、いまのフェーズ、大きいボタン 4 つ（寝る／起きた／ただいま／今日休む）
2. **記録**：気分 5 段階（▲▲+2〜▼▼-2）＋ひとことメモ、直近の記録一覧と取り消し
3. **レポート**：同期フォルダの最新 PDF を開く・共有
4. **設定**：同期フォルダの接続、通知のオン/オフ、使用状況の許可

## 通知
| タイミング | 内容 |
|---|---|
| lastcall（閉店の 40 分前） | 「長い処理はもう投げんとき」 |
| 閉店 | 「寝るなら今」＋［寝る］ボタン付き通知 |
| ハード | 「最低睡眠ラインも切ったで」＋［寝る］［今日休む］ |
| 出発 15 分前 | 「そろそろ準備」（起きた記録があるときだけ） |

- `schedule.json` を読むたびに、この先 14 日ぶんを予約し直す
- 『起きた』『今日休む』が記録されたら、その日の残りの通知を取り消す

## 実装ステップ
| # | 内容 | 終わりの条件 |
|---|---|---|
| 0 | リポジトリ・データ形式（このコミット） | docs が揃ってる |
| 1 | KMP プロジェクトの雛形、`shared/model` と JSON の読み書き | `data-format.md` のサンプルが読み書きできるテスト |
| 2 | PC 版に `schedule.json` 出力と `events-android-*.jsonl` 取り込みを追加 | PC の pytest に追加して通る |
| 3 | 同期フォルダ（Drive）の読み書き | 実機で書いたイベントが PC のレポートに出る |
| 4 | 今日画面＋ウィジェット＋記録 | ワンタップで記録→PC に届く |
| 5 | 通知の予約と取り消し | 実機で閉店通知が鳴る／起きたで消える |
| 6 | 画面利用の集計（`screen` イベント） | PC の自動起床判定がスマホ利用で区切られる |
| 7 | レポート画面（PDF を開く・共有） | 訪看さんにスマホで見せられる |

## 実装前に確かめること（未確認）
- **Drive の書き方**：`drive.file` スコープでアプリが作ったフォルダに書けるのは確実やけど、PC が書いた `schedule.json` を読めるかは要検証。だめなら「アプリが作ったファイルを PC が上書きする」運用か、Firebase に切り替え
- **正確な時刻の通知**：Android 12 以降は正確なアラームに許可が要る（`SCHEDULE_EXACT_ALARM`）。自分用 APK なら許可すれば済むが、Play で配る時は方針の確認が必要
- **使用状況**：`PACKAGE_USAGE_STATS` はユーザーが設定画面で許可する特別アクセス。端末メーカーによってはバッテリー最適化でバックグラウンド集計が止まる
- **PC の Google ドライブのパス**：`H:\マイドライブ\...` を実機で確認

## v1 以降（配布を考えるとき）
- 計算ロジックを `shared` に移植して、PC 版なしでも動くように（初期設定 3 問：出る曜日・家を出る時刻・寝たい時間）
