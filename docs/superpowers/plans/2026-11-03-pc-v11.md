# PC 版 v11 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** [pc-v11-design.md](../../pc-v11-design.md) の 5 項目（E shl ヘルプ，D カレンダー複数，C 通知音，A 事後報告，B 強制モード）を，今の Python + PowerShell 構成に足す．

**Architecture:** 判断は `pc/shiftlock.py`（hook / tick / CLI），OS 操作は `pc/guard.ps1`．状態は書き手ごとのファイル．hook の exit 2 はキーワード応答とハードロックだけ．強制の入口は `shl enforce on` の対話 `y/N` のみで，hook は触らない．

**Tech Stack:** Python 3.8+ 標準ライブラリのみ，pytest（WSL の `.venv`），Windows PowerShell 5.1（UTF-8 BOM + CRLF），cmd（ASCII + CRLF）．

**Spec:** [docs/pc-v11-design.md](../../pc-v11-design.md)（現行仕様は [docs/pc-spec.md](../../pc-spec.md)，形式は [docs/data-format.md](../../data-format.md)）

## Global Constraints

- hook: 失敗時に exit 2 を返さない．exit 2 はキーワード応答とハードロックだけ（CLAUDE.md）．
- 強制（B）: 宣言は `shl enforce on` の対話 `y/N` のみ．`--yes` 等の非対話入口を作らない．強制を促す通知・質問・Claude への文脈を入れない．Claude Code から宣言・解除・設定変更をしない（CLAUDE.md「絶対」）．
- アプリを個別に止める処理は入れない．
- `*.ps1` は UTF-8 BOM 付き CRLF，`*.cmd` は ASCII のみ CRLF，`*.py` は UTF-8 LF．
- 時刻はローカル（JST），関数は `now` を引数で受ける．ユーザー向け文は関西弁．
- 形式を変えるものは先に `docs/data-format.md` を直す（A，B，D）．
- 実行フォルダ（本番）には触らない．deploy / install は本人が起きてから行う．
- ブランチ: 積み上げ式．`dev` → `docs/pc-v11-design` → `update/shl-help` → `feature/calendar-sources` → `feature/notify-sound` → `feature/late-report` → `feature/enforce` の順に，前のブランチから切る．PR の base は前のブランチ．マージは本人がこの順に行う（自動モードではマージしない）．1 機能 1 issue．コミットは日本語 `<型>(スコープ): タイトル`．

## Review Focus

1. hook に `出た`（2 文字）を足すので，普通の文の先頭に `出た` が来るプロンプトを食べないこと → A のテスト `test_past_report_does_not_eat_normal_prompt`．
2. `今日休む` を出庫最終の後に打ったとき，翌日ではなく今日が休みになること．翌日の乗務に影響しないこと → A `test_today_yasumi_after_start_latest`．
3. 強制が **同意なし・STOP.txt あり・起動直後・離席中・時間切れ・回数上限** のどれでも発動しないこと → B `test_enforce_never_fires_without_*`．
4. 旧 `calendar.json`（off/work 直下）と旧 `ics_url` 設定のまま tick が動くこと → D `test_calendar_legacy_*`．
5. 通知音のパスが無い・拡張子が未対応でも通知自体は出ること（Python は `sound=""` を返し，guard.ps1 は失敗を握る）→ C `test_sound_missing_file_gives_empty_and_warns`，guard.ps1 の `try/catch`．
